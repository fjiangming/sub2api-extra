# 运营中心用户画像设计 Demo

用浏览器直接打开 `index.html` 即可预览。无需安装依赖、构建或启动服务；图表与图标均为本地资源。其他模块导航仅用于展示新 tab 在运营中心中的位置。

所有用户与用量都是模拟数据，示例快照为北京时间 2026-10-13，覆盖 2026-09-14 至 2026-10-13。图表、消费占比、用户明细和详情均来自同一套确定性模拟数据，不读取真实数据库或管理员登录信息。

可交互内容：日期范围、计费类型和平台筛选，请求 / Token / 消费额度口径切换，用户搜索、画像标签筛选、排序和分页，用户详情抽屉中的使用偏好与活跃额度视图，统计口径说明，以及导出当前筛选下全部用户的模拟 CSV。

本目录是待确认的设计原型，没有接入运营中心正式导航、接口或部署。设计和数据方案见 `DESIGN.md`。

本地依赖复用运营中心的 ECharts 6.1.0（Apache-2.0）与 Lucide 0.544.0（ISC），相应许可证保存在 `assets/`。

如需 HTTP 预览，可运行 `node preview-server.cjs`，默认地址为 `http://127.0.0.1:8790`。第二个参数可指定其他端口。预览服务只提供此目录内明确列出的 demo 静态文件。
