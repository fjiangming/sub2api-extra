# 对话日志独立交互 Demo

这是用户确认用的界面原型，采用出站旁路采集的产品方案。只加载本地固定样例，不连接 Sub2API、数据库、模型供应商或正式运营中心；没有实现、安装主站采集钩子。

在 `operations-center` 目录运行：

```powershell
node scripts/conversation-logs-preview.cjs
```

默认地址 `http://127.0.0.1:19906/`，占用时自动换端口，以启动输出为准。仅监听 loopback；静态资源通过独立预览服务提供，不能直接双击 HTML。依赖沿用运营中心现有 Express、Lucide 和 ECharts，不新增发行依赖或正式导航。

## 可确认的交互

- 请求列表：搜索、平台 / 协议 / 完整性 / 时间筛选、分页、请求索引 CSV。
- Raw 详情：选择每次上游尝试、脱敏副本 / 原始样例、自动换行、复制、原样下载、展开全文、归档元数据。
- SSE 保存完整事件字符串；WebSocket 展示双向应用层消息列表，逐消息查看及下载；请求详情中的 WS Request / Response 分别为首条发送及最后一条接收消息。
- 会话视图：按样例明确给出的可信 session 关联，缺标识的记录独立保留，用户 / Key 不跨会话归属混用。文本摘要为内置演示内容，不是生产对话还原算法。
- 采集完整性：完整、不完整、队列丢弃正文、脱敏失败、重试恢复，以及节点中断 / 未接入场景。HTTP 200 与完整性分别展示。
- 保存策略：三种保存版本、邮箱 / 电话 / 正文示例密钥 / IP 替换、最多十条精确文本自定义规则、保留与容量参数、超限行为、处理前后预览。自定义规则先在样例上校验，拒绝改变字段结构、角色或工具关联 ID 的替换；此校验不代表已覆盖所有生产协议。
- 排除用户：按用户名或用户 ID 搜索、多选、清空，按稳定用户 ID 覆盖该用户全部 Key 与协议。保存后对后续模拟请求生效，命中时在构建归档前整条跳过，不生成正文 / 消息 / 元数据 / 索引、会话条目或采集缺口；统计和存储量不增加。历史归档保留，不因编辑名单隐藏或自动删除。
- 在“采集状态”选择模拟请求用户后生成记录，可对比排除与正常用户。排除名单同策略保存在本机，草稿不影响当前采集；旧版策略缺少该字段时兼容为空名单，字段非法或策略读取失败时暂停采集并提示重新保存。
- 策略仅写浏览器专用 `sub2api-conversation-logs-demo-policy-v1` 存储项。修改只影响之后点击“生成模拟记录”的样例；历史副本、策略版本和命中信息保持。刷新保留策略，临时新增记录不持久化。浏览器拒绝存储时不显示保存成功。

## 样例与边界

固定样例基准时间为北京时间 2026-11-15 15:30，32 条请求、37 次尝试。只包含虚构人物、example.com 域名、文档 IP、示例电话号码及明确的 `demo_secret`；没有真实 Key。

Raw 用原始字符串作为唯一下载来源，不 JSON 重编码。样例包含大整数 `9007199254740993`、`1.2300` 数值表达、未知扩展字段和工具关联 ID，用于核对完整保留。颜色标注使用 HTML 转义后的文本，恶意 HTML 样例不能执行。浏览器 SHA-256 是当前所选副本的正文摘要，不是签名或防篡改证明。

脱敏仅为确定性样例值 / 精确文本替换，**不代表已经实现生产 PII 识别、跨 SSE 分片识别、加密、访问隔离或流式脱敏引擎**。原始样例没有加密，也不模拟“解密成功”。真实原文加密、认证 Header 排除、队列 / 磁盘边界、故障隔离、关联凭据及传输路径覆盖留待确认后实现。

页面设置的容量、保留和超限行为不操作真实磁盘或删除数据；模拟采集中断没有后台连接。排除验证仅作用于本机新生成的虚构归档，页面仍加载固定历史样例和用户目录；正式采集需要在源头按可信用户 ID 判定，早于正文复制 / 异步投递，排除数据不得进入旁路队列、错误日志或其他存储。预览没有登录、生产写入、推理调用、计费或补记行为，CSP 禁止业务网络连接。
