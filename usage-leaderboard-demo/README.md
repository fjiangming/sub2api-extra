# Sub2API 用量排行榜设计 Demo

直接在浏览器中打开 `index.html`，无需构建或启动服务。页面使用本地静态资源，可以离线浏览。

也可运行 `node preview-server.cjs`，通过 `http://127.0.0.1:8786` 预览。可用第二个参数指定端口，例如 `node preview-server.cjs 8787`。该服务仅绑定本机地址，只提供 Demo 静态文件。

页面自动跟随系统的浅色 / 深色主题。今日 / 本周 / 本月 / 累计周期、Token / 调用次数排序、前三名、完整 Top 10、个人排名定位、用户详情和榜单规则均可交互。名称展示为脱敏的模拟注册邮箱。

当前只用于确认页面设计，所有用户和用量均为模拟数据，没有连接 Sub2API、数据库或登录服务。示例日期为 2026-10-12（北京时间），当日是周一，因此本周与今日数据相同。

`app.js` 中维护演示数据，`styles.css` 中维护布局与颜色。资源中的 Lucide 图标库采用 ISC 许可证；风景头像来自 Unsplash，来源见 `assets/SOURCES.md`。
